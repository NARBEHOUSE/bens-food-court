# Ben's Food Court

A switch-accessible cooking game: seven restaurants around one food court, built for Benny's Hub by NARBE House.

**Play it:** https://narbehouse.github.io/bens-food-court/

It uses Benny's Hub's shared scan, voice and sound scripts from https://narbehouse.github.io/bennyshub/, so to
test it on your computer, serve it next to a copy of the Benny's Hub site rather than opening this folder on its
own (on its own there is no speech, sound or scanning).
